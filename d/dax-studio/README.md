# dax-studio

[DAX Studio](https://daxstudio.org/) — debug and optimize DAX for Power BI / Excel.

```bash
# Windows — connect to Power BI Desktop or Analysis Services
set DAX_STUDIO=C:\Program Files\DAX Studio\DaxStudio.exe
dap-cli debug repl --adapter dax-studio
```

Query editor, server timings, and query plan analysis.
