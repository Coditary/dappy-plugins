# fusionreactor

[FusionReactor](https://fusionreactor.com) — commercial Java/ColdFusion APM and debugger.

Attach-only target (default port 8088). Configure FusionReactor agent in your app server first.

```bash
dap-cli target show fusionreactor
# Attach via java-jdb or dedicated FusionReactor UI
```

No open DAP API — catalog entry for orchestration and documentation.
